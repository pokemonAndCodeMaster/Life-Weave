# 概览与步骤展开：本次改动和验证

日期：2026-09-27。接续事项 `item-7547b65b4f704829`，实现基线 `155545f19f223324b3c575f81469a99e4b60be19`。这是首版实际使用反馈的修订，不是完整平台验收。

## 用户指出的问题与结果

原来主 tab 叫“工作”，点节点只读目标和结论，产物需跳到另一页。现在主 tab 是“概览”，图上的节点显示状态和产物数量，点击后在图下展开：

- 这一步做什么、当前进展或结论；内容相同时不重复。
- 前置和后续步骤，可按真实依赖切换，不强行线性化并行工作。
- 本步关联产物的实际正文。单份默认打开，多份可切换；研究、人工 Markdown、开发阶段与固定代码交付复用同一阅读器。也可进入成果页阅读。
- “讨论这一步”带步骤说明、状态、当前记录及成果引用进入同一事项的讨论草稿；明确为仅讨论，用户发送前不执行。当前阅读的产物排最前；最多带 8 个前置名称和 8 份产物引用，超出部分明确显示数量，说明与结论保留。最大 80 节点 / 79 依赖 / 80 产物组合的草稿低于 12,000 字符，兼容 20,000 字符输入上限。
- 计划编辑定位到本步。共享背景、步骤引用和运行记录按需展开。

所选步骤进入 URL，刷新、返回及成果页切换不会丢失所选步骤。关闭详情回到图上对应节点。没有关联产物、关联产物读取失败和完成但无产物分别说明，不能把整件事项的成果误挂到每一步。

- 真实开发事项分别读到 1,953 字符方案正文与固定代码交付；下载 ZIP 并解析 manifest，核对 3 个交付文件；两个产物切换、实际 Git diff 均可读。
- 人工事项区分无产物与有正文步骤；键盘打开、标题焦点、成果页返回、刷新恢复、收起返回节点、讨论引用及实际输入框逐项检查。整个浏览器读取旅程记录到写请求 0、JS 异常 0。
- 390px 阅读真实 GSSM 正文、公式和图片；长提交号可换行，页面无横向溢出。
- 独立审阅发现的窄屏长文本溢出、后台轮询收起差异已修复。轮询返回新对象时按稳定的产物标识/版本/状态决定是否重读，显式开发验收变更另行刷新。

修复后的[独立复核](independent-review/review.md)另用真实页面确认：390px 的完整提交号、12 个公式、6 张表格及图片不撑宽页面；概览和成果页分别经历一次真实 work-view GET 200 后，差异仍展开、滚动位置及正文 DOM 保持，且未重新请求 Run 或交付正文。

## 使用边界

这轮改的是呈现、阅读和导航，没有新增任意节点自动执行、重跑或调度。旧研究只有已经留下的粗粒度步骤，缺少的过程不能补造。事项完成和知识接受仍走原来的用户决定；报告和代码能读不等于已验收。完整屏幕阅读器及 WCAG 审计、真实手机设备、不同空间恰好同 ID 的完整数据场景未验证。
