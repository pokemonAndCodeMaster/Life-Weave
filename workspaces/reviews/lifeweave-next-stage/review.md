## 首阶段需求理解

### 场景和想要的变化

用户在 ChatGPT 中说“我想精读 Qwen-Drive，弄清楚它对我的工作有什么用”，不必先分类对象、手工新建多个任务、逐篇勾选资料。讨论中保留原话，找到有关旧工作与知识，形成当前研究问题、已知和未知，并在同一事项中继续。

用户在工作台能读到与对话一致的目标和进展。AI 执行使用可追溯的输入，按阶段返回可读材料；用户可以指出解释不足或方向偏差，下一轮沿同一背景继续。值得留下的知识在推进中形成候选，接受后进入原文，后续任务能找到并引用它。

ChatGPT 入口属于材料明确提出的用户体验，不能用仅在本地页面新建事项来冒充已经打通。如何实际连接本机服务、共享什么数据、授权哪些操作，留到方案阶段核实；本机有 CLI 和 Linear 工具不证明 ChatGPT 已连接 LifeWeave。

### 必须保留的工作行为

1. **捕捉与接续**：保存原始表达，能定位同一目标的已有事项；不确定是否同一件事时给出候选依据，避免自动误合并或每次重复建项。
2. **讨论与当前理解**：记录已经确认的目标、范围和未决问题。候选修改与当前已接受背景分开；不同入口不能各自维护互相覆盖的自由正文。
3. **推荐必要材料和方法**：根据事项给出选择理由、来源与版本，允许用户纠正。找不到或来源冲突时明示缺口；不能把自动选择理解为整库塞入上下文，也不把现有“1 个 Skill / 10 篇知识”无条件升级为未来产品规则。
4. **分阶段研究**：为什么读、论文地图、关键机制、代码对照、与已有知识关联、最终讲解材料都可在同一工作中继续。阶段用于组织理解，不机械拆成六条必须单独审批的任务。
5. **过程中的知识候选**：指出本次发现、来源和拟修改的已有知识位置，展示前后差异。发现已有解释不准确时允许纠正，不只是追加新笔记。接受前不覆盖正式原文，失败或冲突可解释。
6. **结果与反馈**：反馈绑定具体尝试、原文位置与输入版本；重试能够接上相关反馈。事项完成仍以约定结果及审阅为准，不由执行器退出码决定。
7. **跨会话读取**：新的对话从当前已保存记录找回目标、阶段、成果和下一步，保留当轮证据，不要求用户重新解释全文。

### 首阶段必须交付的结果

交付包含两部分：一份有证据与未覆盖范围的 Qwen-Drive 深度阅读成果，以及一条他人能够重新操作的“讨论—事项—研究—知识候选—审阅—接续”使用过程。只写出一篇报告，或只新增连接接口，都不能证明这条过程完成。

首阶段不要求自动排全周时间、不要求自动修改并发布 Skill、不重建现有执行器。后续规划需要真实日历或用户明确提供的可用时间，不能推测空闲；能力改进需要真实重复反馈和前后对照，不能凭固定次数或 Agent 自评直接发布。

### 完成标准

| 实际操作 | 应观察到的结果 |
| --- | --- |
| 从一句论文兴趣开始讨论，并再次继续同一目标 | 找到原工作及当前理解，原话和未决问题可读，不产生无理由重复事项 |
| 调整研究目的并在另一入口打开 | 看到同一已确认目标；候选和已确认内容区分，旧运行背景仍可追溯 |
| 发起一轮研究 | 材料和方法选择有理由，运行输入固定，结果可读且能回到依据 |
| 指出“训练数据讲得不清楚”，再继续 | 下一轮能定位反馈和相关阶段，修订结果说明改变了什么 |
| 采纳、拒绝一项知识修改，再制造源版本变化 | 采纳更新正确原文，拒绝不改正文，来源变化产生冲突而非覆盖 |
| 换一个新会话接续 | 找回阶段、已完成成果、知识候选及下一动作，不以聊天全文代替当前记录 |
| 中断执行或连接失败 | 明确失败位置、已有产物和可继续的动作，不虚报同步或完成 |

GSSM 用于下一次复用验证，检验用户是否还要重复教同一套方法，以及哪些研究步骤属于领域特例；在第二例真正做过之前，不宣布形成通用论文研究能力。

## 两个论文场景的核实边界

[Qwen-Drive-1.0 的 arXiv 页面](https://arxiv.org/abs/2609.00111) 确认论文标题、2026-08-31 提交时间，以及外置 BEV 感知模块和规划专家的概述；其 [官方 GitHub](https://github.com/QwenLM/Qwen-Drive-1.0) 当前可见代码和文档入口。本轮只核实对象与入口，没有精读全文或检验算法效果，不能把材料中的全部技术解释视为已经复核。

[Nature 的 GSSM 论文摘要](https://www.nature.com/articles/s42256-026-01189-w) 描述的是从自然驾驶数据学习碰撞风险。它可以作为候选研究对象，但不能仅因简称相同就认定是用户所指的那篇，也不能据此判定“数据分布/稀缺性”的联想错误。第二个任务开始前应确认论文身份，并通过具体方法再判断关联。
